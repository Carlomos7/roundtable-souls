Roundtable Souls
================

Double-click RoundtableSouls.exe. The window has four pages on the left:

  Play       Your character and Play. The line under the banner says what
             will start (me3, Seamless, Revive). Leave the window open while
             you play; it can be minimised. Launch log opens on an error.

             Setup is folded unless something is wrong. Open it to switch
             profiles, or Browse to a .me3 file or NightreignRevive\
             installation.json.

  Co-op      Session password (eye icon shows it), difficulty scaling
             presets (percent per extra player, only the host's values
             count, applied at the next game start):
               Seamless default  35 % enemy HP, 100 % boss HP, small poise
                                 bumps, no extra damage.
               Party of 3 (Nightreign rule)
                                 Nightreign's own rule: +100 % HP per extra
                                 player for mobs and bosses, +30 % poise,
                                 damage unchanged (a Nightlord has 3x its
                                 solo HP with three players).
               Party of 4 / 5 / 6
                                 Same feel for a bigger party: smaller
                                 steps per player (67 / 50 / 40 % HP) so a
                                 full party of 4, 5 or 6 lands on the same
                                 3x total, not 4x to 6x. Pick the one
                                 matching how many of you play together.
               Custom            your own six numbers.
             Save sits on a bar at the bottom of the Co-op page, so it stays
             on screen while you scroll. It stays off until something differs
             from the file, and the bar names what is waiting and turns
             violet. A confirmation appears when you save. Those values apply
             the next time you start. Play saves them too. Discard puts the
             page back to the file.

             "Share with a friend": all your
             Seamless settings as one highlighted block of JSON. Copy sends
             it, Paste + Apply takes a friend's; Apply shows what would
             change and asks first. Save with the bar at the bottom of the
             page, or just press Play.

             Gameplay, Save file, and Language use ordinary form controls:
             On/Off switches, named menus (Name, Hidden, Ping; Co-op or
             Standard save; Mute to Max), and a short line of what the
             setting does. The i button opens a short explanation. The
             numbers Seamless stores in the file stay behind the scenes.
             Open a group, change what you want. The Save bar at the
             bottom of the page writes them.

  Mods       Packages and natives me3 will load, on or off, with Options
             and Remove on every row. Install mod takes a .zip, .7z or .rar
             (rar through Windows' own tar, 7-Zip or WinRAR) or a folder,
             works out whether it is a package (game folders such as parts,
             chr, msg, or regulation.bin) or a native DLL, copies it beside
             the others and adds it last in the load order. Options: loaded
             on/off, and for DLLs optional, load early, initializer and
             finalizer, plus Load after / Load before against the other
             entries. Remove deletes the entry and, only if you tick it,
             the folder. New profile creates a .me3 in me3's profile folder,
             empty or copied from the current one; Delete profile moves the
             file into deleted-profiles. Refresh re-reads the file.
             Profile settings: the me3 options a profile can set (memory
             patch, Arxan, online matchmaking with its ban warning, heap
             size, save file name) as menus, written into the .me3 with a
             .bak. Conflicts: every file two enabled packages both ship,
             with the winner by load order (later wins, as me3 does).
             Read-only; Rescan after changing mods.
             Edit profile is the me3 text, with TOML highlighting. Save profile appears on the title
             when the text differs from the file, and writes a .bak.
             In that box and in the share box on Co-op: Ctrl+/ comments or
             uncomments the selected lines (# in the profile, // in the
             share JSON, which Apply ignores), Tab and Shift+Tab indent or
             outdent a selection, Ctrl+D duplicates the line. Ctrl+Z undoes
             each one in one step.

  Saves      Each save file (Standard .sl2, Seamless Co-op .co2) is its own
             panel. Three short status chips under the file name say at a
             glance whether it loads, whether the items are vanilla, and
             whether editors can open it. Characters first.

             Review & fix opens the save on its own page. Characters sit on
             the left (pick one, or All); on the right each finding is a
             tick box in its own card: May not load, Remove mod items (with
             a search box and a filter by mod, All / None per mod, worn
             gear greyed with the reason), Cleanup, Quest flags, For save
             editors. Loading, quest and checksum fixes start ticked;
             removals start off. The bar at the bottom names exactly what
             Apply will do. Apply asks once, backs the file up, writes,
             verifies, and then offers Undo at the top of the window.

             Backups, at the bottom of the Saves page, lists every dated
             copy with what it was taken before (hover for the full list).
             Restore puts one back after copying the current file, so a
             restore can itself be undone. Delete removes a copy. Under "Worth knowing": optional notes
             for save editors (regulation repair), mod/Seamless items, and
             known quest soft-locks — calm wording, not alarms. Copy report
             puts the full technical check on the clipboard. Repair rewrites
             only the regulation block and keeps a .bak. Fix quest flags
             clears a known soft-lock (Ranni, Radahn / Morgott / Radagon
             warp, Sealing Tree, Unte golem, early Erdtree) the same way
             the save editors do: it shows what changes, backs the file up
             into save-fix-backups, flips only those flags, and re-signs
             the character. Restore vanilla, Fix quest flags and Fix
             loading each open a checklist first: every character, item
             and fix is its own tick box (All / None per character), worn
             gear is shown greyed with the reason, and the line above
             Apply says exactly what will change. Untick anything you
             want to keep. Fix checksums recomputes a stale character or
             profile checksum, same backup. Fix loading covers the states
             that hang the loading screen: Torrent at 0 HP but active, a
             position that is on no map, standing in the Land of Shadow or
             carrying its entry flag without the DLC installed, junk in the
             DLC block, and weather out of sync with the map. Same confirm
             and backup. A save damaged by a crash while saving (torn
             write) is named as such and left alone. Restore vanilla is the one for
             going back to a standard save: it lists every item outside the
             vanilla + DLC list by name and mod (Seamless Co-op goods, mod
             gear such as Tarnished Pack), removes them from the held and
             chest lists, empties quick and pouch slots that pointed at
             them, clears leftover item rows and the quest soft-locks, then
             re-signs. Worn mod gear is kept and named: take it off in-game
             and run it again. Same backup folder. To .sl2 makes a standard copy
             (backs up first; asks again if notes remain). Buttons open the
             save folder and the newest backups folder. A number on the
             Saves icon means one of those repairs is available; ordinary
             mod-item notes never show it.

  Offline    If Steam's login network is down, the Play page tells you and
             offers "Play offline" (also on the Tools page). That starts the
             same setup WITHOUT Seamless Co-op, so the game loads your
             standard save (ER0000.sl2), not the co-op one; co-op itself
             needs Steam online, nothing can change that. Steam must be
             running; if it shows a connection dialog, choose "Start in
             Offline Mode" first. On Tools you can also skip Revive for
             that launch, skip starting Steam if it is already open, and
             skip the confirmation next time. Your real profile is never
             rewritten; a temporary .offline.me3 is used.

  Tools      Locations: a custom me3.exe, a game exe outside Steam
             (me3 launches it directly), and the profile folder. Blank
             means detect; the profile folder follows what me3 info says.
             me3: installed version, a once-a-day notice when a newer
             release exists (nothing is installed for you), and buttons for
             me3's install folder, its own logs and its profile folder. Play session also has Boot
             boost, Show intro logos and me3 diagnostics.
             Save checks: Shadow of the Erdtree is detected from DLC.bdt
             next to the game; set Not installed when checking a save for
             someone without it, so DLC items show under Remove mod items.
             Tarnished Edition gear is official paid content
             and counts as vanilla when the pack flag is set on the save
             (read from the save by default; Always / Never override it).
             Play session: turn each step around the game on or off. Back
             up saves before Play (off by default), clear leftover
             processes before launch and after quitting, repair saves
             after quitting, and the warning bar about leftover processes.
             Also: Repair saves now, Clear dead game processes (the dead
             eldenring.exe left behind on exit that makes Discord think the
             game is still running; asks for admin once), logs and data
             folders, dark / light theme, and the logo (follow theme, or
             lock to the gold or frost plate). Windows rounds the square.
             The theme and logo change right away. Picking a different
             setup on the Play page is remembered immediately.

Why "repair saves": playing through me3 leaves a block at the end of the save
file full of garbage. The game does not mind, but save editors do. The repair
puts the game's real data back. Every rewritten save is backed up first into a
regulation-fix-backups folder next to it. Nothing else in the save is touched.

Needs: Windows, Steam with Elden Ring, and either me3 installed or a
Nightreign Revive installation (which brings its own me3). Windows may show a
SmartScreen warning the first time because the exe is not signed; choose
"More info" > "Run anyway". Keep the exe in its own folder; it writes a small
settings file and the logs next to itself.

Where it keeps its files: launcher_settings.json and a logs\ folder next to
the .exe when that folder is writable, otherwise in %LOCALAPPDATA%\RoundtableSouls.
If anything goes wrong, logs\launcher-errors.log has the details.
